# Sjekkliste før innlevering

## A. Frist og innlevering

- [ ] Tilbudsfrist (dato, klokkeslett) er notert, og innlevering er planlagt med god margin
- [ ] Riktig innleveringskanal (Mercell, eu-supply, Visma TendSign, e-post – kun hvis tillatt)
- [ ] Alle rettelser og tilleggsopplysninger fra oppdragsgiver er lest og tatt hensyn til
- [ ] Publiserte svar på spørsmål er lest; svar som endrer krav er innarbeidet

## B. Form

- [ ] Tilbudsbrev på oppdragsgivers mal, ikke egen mal
- [ ] Alle felt i tilbudsbrevet er fylt ut
- [ ] Signert av person med fullmakt (daglig leder, signaturrett etter Brønnøysund eller skriftlig fullmakt vedlagt)
- [ ] Vedståelsesfrist er ikke endret eller forkortet
- [ ] Språk som krevd (norsk/skandinavisk/engelsk)
- [ ] Filformat og filnavn som krevd; ingen låste eller passordbeskyttede filer med mindre det er krevd
- [ ] Sidebegrensninger overholdt (besvarelse over maks sider kan bli ignorert eller gi avvisning)
- [ ] Forretningshemmeligheter er merket hvis grunnlaget ber om det

## C. Kvalifikasjon

- [ ] ESPD eller egenerklæring fylt ut og konsistent med øvrig dokumentasjon
- [ ] Skatteattest (merverdiavgift og skatt) ikke eldre enn grunnlaget tillater
- [ ] Firmaattest / registrering i Enhetsregisteret
- [ ] Økonomisk dokumentasjon (årsregnskap, kredittvurdering) som krevd
- [ ] Referanser oppfyller kravene til antall, verdi, alder og relevans
- [ ] Kvalitets- og miljøsertifikater (ISO 9001, ISO 14001, Miljøfyrtårn) eller likeverdig dokumentasjon
- [ ] HMS-egenerklæring / sentral godkjenning der det kreves
- [ ] Ved støtte fra andre virksomheter: forpliktelseserklæring vedlagt
- [ ] Ved underleverandører: opplysninger som krevd

## D. Minstekrav og kravspesifikasjon

- [ ] Hvert «skal»-krav er besvart eksplisitt
- [ ] Ingen besvarelser sier «delvis», «planlagt», «på sikt» om absolutte krav
- [ ] Tekniske verdier (kapasitet, responstid, oppetid, mengder) er lik eller bedre enn kravet
- [ ] Krav fra standarder som er gjort til del av grunnlaget (NS 3420, NS-EN …) er oppfylt

## E. Forbehold og avvik

- [ ] Ingen henvisning til egne salgs- eller leveringsbetingelser
- [ ] Ingen skjulte forbehold (se SKILL.md, punkt 4)
- [ ] Eventuelle forbehold står i tilbudsbrevet, er presise og er priset der grunnlaget krever det
- [ ] Ingen forbehold mot kontraktsvilkår som grunnlaget sier ikke kan fravikes

## F. Pris

- [ ] Oppdragsgivers prisskjema brukt uendret (ingen slettede rader, kolonner eller formler)
- [ ] Alle prisfelt utfylt; «0» eller «inkludert» bare der det er tillatt
- [ ] Mva. behandlet som krevd (ekskl./inkl.)
- [ ] Sum i prisskjema = sum i tilbudsbrev
- [ ] Ingen priser i fritekst som avviker fra skjemaet
- [ ] Ingen enhetspriser som kan oppfattes som unormalt lave uten forklaring
- [ ] Opsjoner priset hvis det kreves

## G. Tildelingskriterier

- [ ] Hvert kriterium og underkriterium har et eget, tydelig merket svar
- [ ] Svarene er strukturert i samme rekkefølge som evalueringen
- [ ] Dokumentasjon som evalueres (CV-er, planer, miljødokumentasjon) er vedlagt
- [ ] Klima- og miljøsvaret har konkrete, målbare og dokumenterte tiltak

## H. Konsistens

- [ ] Samme organisasjonsnummer, firmanavn og kontaktperson i alle dokumenter
- [ ] Samme nøkkelpersoner i CV-er, bemanningsplan og løsningsbeskrivelse
- [ ] Samme datoer, mengder og priser overalt
- [ ] Ingen rester av tekst fra tidligere tilbud (feil oppdragsgiver, feil prosjekt, feil kommune)
